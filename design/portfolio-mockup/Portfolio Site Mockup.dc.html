Set up automated threat alerts in InsightEdge

Automated threat alerts notify your security team the moment InsightEdge detects a risk that matches your policy. This article covers how to create an alert policy and connect it to a notification channel.

Before you start

  • You need Admin or Security Lead permissions on the workspace.
  • At least one data source must be connected and actively scanning.
  • To receive alerts by Slack or email, connect the channel first in Settings > Integrations.

Create an alert policy

  1. In the left sidebar, select Threat Detection > Alert Policies.
  2. Select New policy.
  3. Name the policy and choose a severity threshold: Critical, High, or Medium and above.
  4. Under Scope, select the data sources the policy applies to.
  5. Select Save to activate the policy.

Configure notification channels

  1. Open the policy you created and select Notifications.
  2. Select Add channel and choose Email, Slack, or Webhook.
  3. Enter the destination — an email address, Slack channel, or webhook URL.
  4. Select Send test alert to confirm delivery.
  5. Select Save.
