# Secyra (2025)

A Senior Technical Writer take-home assignment for a data-security platform ("Secyra"/the InsightEdge Platform below), covering a real feature end-to-end across four documentation formats: a knowledge base article, a release note, UX microcopy, and a troubleshooting guide.

- **[Knowledge Base Article](knowledge-base.md)** — full instructions for a new "manage classifications" feature (add, change, remove, restore).
- **[Release Note](release-note.md)** — a short, engaging announcement of the same feature for a What's New feed.
- **[Microcopy](microcopy.md)** — alert copy and remediation steps for a missing-permissions system health alert.
- **[Troubleshooting Guide](troubleshooting-guide.md)** — diagnosing and fixing a Snowflake integration permissions issue.
